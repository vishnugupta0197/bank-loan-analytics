# Bank Loan Analytics Dashboard

## Project Overview

The Bank Loan Analytics Dashboard is an interactive Power BI dashboard designed to analyze bank loan applications, funded amounts, repayments, loan quality, and borrower characteristics. The report provides portfolio-level KPIs and enables users to explore loan trends and customer characteristics through interactive visualizations and filters.

---

## Business Objectives

- Monitor overall loan application volume and funded amounts.
- Compare funded amounts with amounts received.
- Analyze Good Loan and Bad Loan performance.
- Track monthly loan application trends.
- Explore applications by Loan Status, Loan Term, Home Ownership, Loan Purpose, and State.
- Compare Average Interest Rate and DTI Ratio across loan statuses.

---

## Dashboard Pages

### 1. Summary Dashboard

#### Key Performance Indicators (KPIs)

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio

#### Additional Analysis

- Good Loan vs Bad Loan Applications
- Funded Amount vs Amount Received by Loan Status
- Loan Applications by Status
- Average Interest Rate by Loan Status
- Average DTI Ratio by Loan Status

### 2. Overview Dashboard

#### Visualizations

- Monthly Loan Application Trend
- Loan Applications by State
- Loan Applications by Loan Term
- Loan Applications by Home Ownership
- Loan Applications by Purpose
